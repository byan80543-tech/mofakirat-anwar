# مفكرة أنوار — نسخة تطوير المصحف الورقي

هذه النسخة تضيف قارئًا للمصحف الورقي إلى مفكرة أنوار، بجوار مدخل إذاعة القرآن والدروس.

## ما أضيف
- مدخل مستقل باسم **المصحف الورقي** في الواجهة الرئيسية، قريب من إذاعة القرآن.
- عرض صفحات مصحف المدينة المنورة المصورة، صفحة واحدة في كل مرة.
- التنقل بين الصفحات من 1 إلى 604، مع الانتقال المباشر إلى رقم صفحة.
- حفظ آخر صفحة تلقائيًا، وحفظ موضع قراءة يدويًا واستعادته.
- تقليب الصفحات بالسحب على شاشة الهاتف، أو بمفاتيح الأسهم على لوحة المفاتيح.

## مصدر صفحات المصحف
تُحمّل صفحات PNG عند الطلب من مشروع [Miftah-Fentaw/Quran-Images](https://github.com/Miftah-Fentaw/Quran-Images)، وهو ينشر مجموعة 604 صفحة ويذكر في README أن الصور من مصحف المدينة المنورة. المشروع منشور بترخيص MIT؛ راجع [ملف الترخيص](https://github.com/Miftah-Fentaw/Quran-Images/blob/main/LICENSE). ويذكر المشروع المصدر الأصلي للصور: [Quran-PNG](https://github.com/GovarJabbar/Quran-PNG) و[quran.com-images](https://github.com/quran/quran.com-images).

**ملاحظة اتصال:** يتم تحميل الصفحة التي يفتحها القارئ فقط. يحتاج تحميل الصفحات الجديدة إلى الإنترنت؛ لا تتضمن هذه النسخة ملفات الصفحات الـ604 داخل الأرشيف، ولا ندّعي أن القراءة متاحة دون اتصال.
